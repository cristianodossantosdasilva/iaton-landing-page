# Security Policy

## Supported version

The public landing page deployed from the `main` branch is the supported version.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `contato@iaton.ia.br` with the subject `Security report`.

Include the affected URL, a concise description, reproduction steps that do not access third-party data, and any supporting evidence. Do not disclose a suspected vulnerability in a public GitHub issue before it has been reviewed.

## Safe testing expectations

Security research must remain non-destructive and limited to assets owned by this project. Do not perform denial-of-service testing, credential attacks, social engineering, data extraction, persistence, or testing against third-party infrastructure without authorization.

## Scope note

Security validation reduces risk but does not establish that a system is invulnerable. Controls and tests must be reviewed whenever the site gains scripts, forms, APIs, authentication, cookies, analytics, or external resources.
