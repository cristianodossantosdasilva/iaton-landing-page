# IÁTON

Landing page institucional do IÁTON, uma plataforma desktop em desenvolvimento para orquestração supervisionada de agentes de inteligência artificial.

## Proposta

Transformar objetivos em missões rastreáveis, conectar modelos locais e em nuvem e preservar o controle humano sobre decisões críticas.

## Princípios

- Supervisão humana
- Rastreabilidade
- Separação de dados
- Menor privilégio
- Modelos de IA intercambiáveis
- Execução orientada a missões

## Site

A publicação oficial utilizará o domínio `iaton.ia.br`.

## Status

Projeto de tecnologia em desenvolvimento.
